# IT4793GroupProject: Customer Campaign Acceptance Analysis

## Overview

This project analyzes customer demographic, purchasing, and previous campaign data to better understand which customers are more likely to accept a marketing offer. The goal is to use data analysis and predictive modeling to classify customers as likely or unlikely to respond to a future marketing campaign.

This project was developed for **IT 4791 – Applied Data Driven Solutions** at Kennesaw State University.

## Project Objectives

- Explore customer demographics and purchasing behavior
- Identify patterns associated with previous campaign acceptance
- Prepare and clean the dataset for analysis
- Develop classification models to predict customer campaign acceptance
- Evaluate model performance using appropriate classification metrics
- Translate results into useful marketing insights and recommendations

## Dataset

The project uses the **Customer Personality Analysis** dataset from Kaggle, containing over 2,200 customer records.

The dataset includes variables related to:

- Income
- Birth year
- Education
- Marital status
- Children and teenagers in the household
- Customer spending
- Purchasing behavior
- Previous marketing campaign responses

## Analytical Approach

The project will combine **descriptive and predictive analytics**.

Descriptive analysis will first be used to explore the dataset and better understand customer characteristics, purchasing behavior, and previous campaign responses.

Predictive modeling will then be used to classify customers based on their likelihood of accepting a marketing offer. Classification methods will be selected and compared as the project progresses.

## Model Evaluation

Model performance will be evaluated using classification metrics including:

- **Accuracy** – How often the model makes the correct prediction overall
- **Precision** – How often customers predicted to accept an offer actually accept
- **Recall** – How many actual responders the model successfully identifies
- **F1-Score** – A combined measure of precision and recall
- **Confusion Matrix** – A breakdown of correct and incorrect classifications
